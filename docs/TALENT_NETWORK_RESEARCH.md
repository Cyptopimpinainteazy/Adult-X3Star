# Talent-network reference

Public primary HTML reviewed on 2026-11-27. No reference-site account was created, media downloaded, or authenticated contact workflow tested.

- [JuicyStarz homepage](https://juicystarz.com/) connects talent discovery, recent posts and jobs, with profile creation calls to action. The useful pattern is connected navigation rather than a standalone jobs list.
- [Talent search](https://juicystarz.com/search) exposes location filters and public profile cards. X3Star uses its existing names, tags, niches and optional self-declared location, without inferring demographic attributes.
- [Producer directory](https://juicystarz.com/producers) distinguishes producer/company accounts and describes that label as self-declared. X3Star instead derives its public company view from the reviewed identity on an active paid listing; it does not claim company verification.
- [Jobs hub](https://juicystarz.com/jobs-hub) presents hiring, available work, collaboration and services as different posting intents. X3Star already has hiring/available kinds and a collaboration category, so those are reused rather than replaced.
- [Location posts](https://juicystarz.com/posts) and the [Denver view](https://juicystarz.com/posts/denver) connect local browsing, categories and intent. X3Star connects its existing state guides to actual state-filtered records; it does not generate empty city pages.

The reference advertises messaging and free joining, but this review did not verify message delivery or employer pricing. X3Star's private inquiries and paid employer placement retain their own existing behavior and billing boundaries. No competitor claims, copy, profiles, images, reviews or payment terms are imported.

Visual inspection remains unavailable because the browser access host returned no enabled surfaces. The decisions above are based on primary public HTML structure, not a claimed pixel-level visual comparison.
